# FDM 공차 (0.4mm 노즐 / 0.2mm 레이어 기준)

단위는 전부 mm. OpenSCAD·build123d·CadQuery 모두 무단위 숫자를 mm 로 취급한다. 인치를 쓰지 않는다.

## 최소 치수

| 항목 | 값 | 비고 |
|---|---|---|
| 최소 벽 두께 | **1.2** | 0.4 노즐 × 3 라인. 0.8 도 되지만 잘 깨진다 |
| 최소 피처 (XY) | 0.8 | |
| 최소 피처 (Z) | 0.2 | 레이어 한 장 |

## 끼워 맞춤 — 공칭 치수에 더할 값

| 종류 | 보정 | 예 |
|---|---|---|
| 압입 (press fit) | **−0.05 ~ 0** | 베어링 하우징, 자석 자리 |
| 헐거운 끼움 / 미끄럼 | **+0.2 ~ 0.3** | 뚜껑, 슬라이드 |
| 힌지 · 회전 | **+0.4** | 움직이는 축 |

## 구멍

프린트된 구멍은 실제보다 **0.1~0.2 작게** 나온다. 볼트 관통 구멍은 지름을 키운다.

| 볼트 | 관통 구멍 | 나사 조임(tap) |
|---|---|---|
| M3 | **3.4** (넉넉히 3.6) | 2.8 |
| M4 | **4.5** | 3.7 |
| M5 | **5.5** | 4.6 |

너트 자리(M3 육각 너트): 대변 **5.6**, 두께 **2.6** (공칭 5.5 / 2.4 에 여유)

## 형상

- **오버행 45도** 초과하면 서포트가 필요하다. 설계로 피하는 게 항상 낫다.
- **가로로 눕힌 구멍**은 위쪽이 처진다. 세우거나 **물방울(teardrop)** 모양으로 뚫는다.
- **브리지**는 10mm 정도까지 서포트 없이 건너간다.
- **elephant foot**: 첫 레이어가 0.1~0.2 퍼진다. 정밀 끼움면을 베드 면에 두지 않는다.
- 힘을 받는 방향과 **레이어 방향**이 수직이면 잘 부러진다. 프린트 방향을 먼저 정하고 설계한다.

## 매니폴드

- 관통 구멍은 항상 양쪽으로 `eps`(0.01) 씩 더 뚫는다. 딱 맞으면 coplanar face 로
  z-fighting 이 생겨 non-manifold 가 된다.
- `part.json` 의 `simple: true` 가 닫힌 입체라는 뜻이다. false 면 슬라이서에서 깨진다.
